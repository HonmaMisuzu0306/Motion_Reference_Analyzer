# MRA V1.0 使用说明

## 安装和启动

运行交付目录中的 `MRA-1.0.0-x64-setup.exe`（构建目录原名为 `Motion Reference Analyzer_1.0.0_x64-setup.exe`）。安装后从桌面或开始菜单打开 MRA。
支持 Windows 10/11 x64，需要系统的 Microsoft Edge WebView2；安装器会在缺少时引导安装。
应用自带 Python 分析运行时，不要求安装 Python、Node.js 或开发依赖。
首次启动自动创建本地服务并选择空闲回环端口，退出后回收本次启动的服务。

默认项目、缓存、设置和日志保存在 `%LOCALAPPDATA%\MotionReferenceAnalyzer`，不写入程序安装目录。
开发模式沿用仓库的 output。测试或便携使用可通过 MRA_DATA_DIR 指定独立数据目录。
安装更新和卸载不会清理此数据目录；项目结果仍需用户自行备份。

## 先用基础分析

在“项目”中导入视频，点击“基础分析”。无需模型即可进行分镜、代表帧、CV 运动测量和音频节奏分析。
基础分析明确省略视觉语义、OCR 和排版语义；空字段不表示“没有文字”或“没有效果”。
预览、镜头列表和底部时间轴共用定位。重复选择镜头会暂停并回到起点。
面板分隔线可拖动或用方向键调整，面板可折叠；“恢复布局”重置大小。

## 准备完整分析所需模型

MRA **不附带模型权重，也不提供内部模型下载**。“模型”页提供配置方向、模型大小和官网入口。

1. 从 [Ollama 官网](https://ollama.com/download/windows) 自行安装 Ollama，并按其官方说明安装模型。
2. 推荐先选 [qwen3-vl:4b](https://ollama.com/library/qwen3-vl:4b)。2b/8b 为候选配置，尚无本项目完整验收；文件大小不等于运行内存需求。
3. 回到“模型”页重新检测，确认模型支持图像输入，点击“选用此模型”，或在“设置”填写模型标识。
4. 在“模型”页查看“本机 OCR 模型”。MRA 只读检查 `%USERPROFILE%\.paddlex\official_models` 中完整的 PP-OCRv5 推理模型；已发现的模型选择识别语言后点击“选用本地 OCR 模型”，无需重复下载。其他位置的已有模型可在“设置”手动选择。
5. 尚无模型时再从 [PaddleOCR 官方模型页](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/OCR.html) 查找 **PP-OCRv5** 检测和识别推理模型，自行下载、解压，并在“设置”添加语言配置。目录应直接包含 `inference.pdiparams`、`inference.json` 或 `inference.pdmodel`，以及带有 `Global.model_name` 的 `inference.yml`；选择推理目录而不是压缩包或训练权重。该网站也展示其他版本，请保持 V1.0 已验证的 PP-OCRv5 配置。未配置的辅助模型被禁用。
6. 保存设置后点击“分析视频”。缺少服务、视觉能力或本地推理文件时会显示原因，不会用假结果替代。

识别目录按语言匹配。PP-OCRv5 通用识别模型可用于中、日、英文；英文已有真实验收，日文自然视频样本准确率尚未验收；不要把候选目录状态视为识别准确率保证。
“本地模型目录已就绪”仅指文件完整，真正加载或推理错误会在分析警告中报告。
已有模型时分析不需要外网；Ollama 本机服务需保持运行。官网入口需要网络。

## 保存、恢复、重连与参考库

导入视频后即可“保存到参考库”，即使尚未分析。项目页面支持打开和修改显示名称。
项目内部身份不随显示名称改变；保存已有项目会保留 ID 与标签。
源素材移动后用“重新定位源视频”选文件，只有完整 SHA256 相同才可接回旧分析。
同名但内容不同的素材应重新导入为新项目。缺少源文件仍可查看已保存的镜头结果与缩略图。
关闭后重开会恢复上次保存项目和选中镜头；未保存的导入不承诺恢复。
参考库支持搜索、筛选、手动标签、镜头播放、制作建议导出与载入工作台。

## 导入开发版旧库

在**空参考库**的“项目”页点击“选择旧库并导入副本”，选择旧 `mra_library.db`，再选择旧仓库根目录
（资产路径为 `output/...` 时应选 Motion_Reference_Analyzer 根，而不是 output）。
源库通过只读快照复制；原 ID、标签和分析结果保留，外部视频保持原位置。
越界资产或缺失引用会取消导入，目标库不会留下半个可用项目。缺失源视频允许导入并随后重连。
已有项目的目标库会拒绝导入，以避免覆盖和 ID 冲突。

## 导出和故障恢复

### 自选单帧和片段

打开项目后，在分析工作台顶部点击“分析当前帧”，软件暂停视频、定位准确画面并直接分析。也可先“取当前帧”或输入秒数点击“定位帧”，用“上一帧 / 下一帧”微调，查看准确预览、实际时间和PTS后点击“分析单帧”。单帧只分析构图、色彩、文字和可见效果，运动、转场、动画和节奏不适用。

片段可用播放头设置入点/出点，手工输入秒数，或点击“使用当前镜头”。出点不包含在选区中，最长60秒；“播放选区”在出点暂停，拖到选区外退出播放限制。点击“分析片段”后后台生成独立结果；少于8秒只给音频波形和瞬态，不估计BPM。只包含一张实际画面的局部镜头改用静态分析，并明确提示运动证据不足。

工作台“局部记录”按钮显示当前项目的记录和进度。打开记录可看准确截图、局部镜头和制作建议，点击“跳到源时间”定位原视频，导出局部JSON或Markdown。“重新分析为新记录”保留旧记录并重新执行；“返回镜头详情”回到原整片结果。部分模型失败会显示“部分完成”和具体警告，已得到的结果仍可导出。离开分析页不会取消后台任务，运行时项目修改和设置保存暂时禁用。

尚未保存的项目会先自动保存。关闭应用会中断未完成任务，重启后标记“中断”，可新建记录重试。源文件缺失或内容改变时可查看截图和导出已有记录；重新分析须关联相同源视频。局部记录使用schema6，库副本导入支持schema3–6。

“导出 JSON”保存结构化项目，“导出 Markdown”保存中文报告。界面会告知文件位置。
数据键和稳定枚举保持接口兼容；新模型自然语言输出要求中文，历史英文结果保留原文。
联系表可从代表帧区域打开；文字轨迹叠加显示平均范围，并非当前帧的精确 OCR 框。
后台启动失败或运行中退出时，会出现“重试启动”和“查看日志位置”。默认日志为数据目录的 `logs/backend.log`。
