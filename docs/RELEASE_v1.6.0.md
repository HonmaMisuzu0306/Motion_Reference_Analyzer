# v1.6.0 · 框选图案，导出 AE 位置跟踪

背景向左滑动、图标向右移动时，可以单独测量图标中心的位置。在 After Effects 中把标注文字设为跟踪空对象的子图层，文字就会随图标移动。

1. 导入原片并运行基础分析。在工作区选择镜头，在「区域位置跟踪」中点击「框选图案并跟踪」。
2. 输入源片时间或点击「使用播放头时间」，再点击「读取定帧图」。工具会显示实际解码到的源帧时间。拖框选中一个轮廓清晰、内部有纹理的图案，也可以用百分比输入选框位置和大小。图案较小时，可拖动详情面板的分隔线扩大定帧图。
3. 设置结束时间，点击「跟踪此区域」。一次最多处理当前镜头中的 30 秒。黄色轨迹标出已确认的位置。遮挡、相似图案、明显变形或突变可能使跟踪提前停止，界面会列出首个未确认位置的源时间。
4. 至少取得两个位置后，点击「导出 AE 空对象 JSX」。在 AE 中运行脚本，会新建与原片显示画幅一致的合成和一个二维空对象。合成的零秒对应所选定帧。若需要叠放原片，应让原片的该时刻对齐合成零秒。

空对象的 X、Y 使用实测中心位置和源视频的实际时间，采样点之间线性插值。它描述图案在画面中的位置。缩放、转动、遮挡后重新出现的图案请另选一段再跟踪。旋转或非方形像素的视频按显示画幅框选。

计算和导出都会核对当前镜头与原片。工作区切换素材后需要重新跟踪。已保存内容摘要的历史镜头可以直接使用。当前跟踪结果临时保留，准备在 AE 中继续使用时请导出 JSX。
