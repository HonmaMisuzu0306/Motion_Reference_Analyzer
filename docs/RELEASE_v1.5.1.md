# v1.5.1 · 在资料库中核对 AE 关键帧的原片

打开资料库中的镜头，在「关键帧试作方案」选中一个时间，再点击「查看原片」。播放器会打开该镜头关联的视频，跳转到关键帧的源时间并暂停。可以用这个操作对照一次往返移动的峰值，或确认旋转何时开始。

本版修复了两种容易看到错片的情况。第一种是在工作区从素材 A 切换到素材 B 后，原播放器仍在请求 A 的下一段。第二种是在资料库保存镜头后，用同名文件覆盖了原片。对已经记录内容摘要的素材，播放器会拒绝不匹配的请求。将正确的原片放回关联位置后，可以继续回查已保存的镜头。

历史项目若没有记录内容摘要，只能按保存的路径找回文件。核对这类记录时，请先确认该位置的文件确实是原片。路径丢失时可在项目页重新关联。
