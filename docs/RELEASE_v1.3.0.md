# v1.3.0 · AE 素材留边与试作模板

平移镜头里的主体回到了原位，途中露出的背景仍需要补画。现在可在实测关键帧旁查看素材左、右、上、下各需补多少像素，以及补画后的总尺寸。工作区、资料库和片段分析均可导出留边脚本。

1. 导入原片并运行基础分析，选择有完整实测运动的镜头，展开「关键帧试作方案」。
2. 查看「素材留边建议」。例如在 320 × 180 的短镜头中，画面向右移动约 63.3 像素后返回，建议向左多画 64 像素，图稿尺寸为 384 × 180。
3. 点击「导出留边 AE 试作脚本」并在 AE 中运行。将该尺寸的静态图稿放入 CONTENT 合成中央，移除校准标记。原画面在新图稿中的左上角应落在（左留边，上留边）处。
4. 打开 MOTION 合成预览。上述示例保留 320 × 180 的输出和原关键帧时间，脚本将素材锚点移到 (224, 90)，让新增的像素留在正确一侧。

对于中心旋转，留边计算会覆盖导出脚本在关键帧之间经过的角度。例如 320 × 180 画面从 0° 连续旋转到 90°，需为四边分别补 24、24、94、94 像素。只检查起止角度会低估途中经过的画面范围。

估算适用于本工具导出的二维图层、中心锚点、线性位置/旋转/等比缩放。手工更改缓动、锚点、父层、透视或运动模糊后请在 AE 中重新核对。源视频在采样之间的真实运动也可能与试作曲线不同。若证据不足、估算超过 AE 的合成尺寸上限或计算无法取得可靠边界，仍可查看测量情况；普通脚本沿用原来的导出条件。脚本会准备画布与锚点，向外补画的内容由创作者提供。

版本验证包括合成几何基准、真实编码视频、后端接口与 JSX 属性检查。真实 After Effects 渲染和已有安装的覆盖升级仍待验证。

手机素材若依靠容器旋转标记显示为竖屏，本版仍按编码画幅分析，位移轴与预览方向可能不同。对此类素材请先按显示方向转码再分析。
