# v1.1.1 · 连续旋转分镜修复

修复 v1.1.0 中连续旋转被识别为大量切镜的回归。复现素材为高对比度、无切镜的 2 秒旋转视频；修复前整片与选区均识别成 48 个镜头。

分镜检测现在使用分布在画面上的双向特征跟踪、仿射对齐及颜色残差来验证旋转和缩放，并按实际帧间隔比较相邻运动。原有平移补偿与单帧闪光判断保留。检测器版本更新为 `spatial-affine-v4`。

新增回归覆盖正反旋转、缩放、组合运动、黑边、局部区间、可变帧间隔、运动中的真实内容切换，以及孤立旋转/缩放跳切。原有真实硬切、闪光与短镜头检查继续执行。

旧分析记录不会被自动改写；请重新分析受影响的视频。原有 v1.1.0 安装包保留供追溯，建议使用 v1.1.1。

仍是画面测量近似。只有两帧且同时伴随内容切换的运动片段可能缺少连续性证据，仍可能被细分；强非刚体运动、遮挡和叠化需要人工核对。合成回归不代表真实视频准确率。
