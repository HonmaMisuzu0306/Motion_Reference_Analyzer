# v1.7.0 · 用两个标记测量同一图案的转动和缩放

给一张旋转的票卡加标注时，可在票卡上选两个印刷标记。A 的中心决定位置，从 A 指向 B 的方向变化决定转角，两点间距相对首帧的变化决定等比缩放。导出后，在 AE 中让标注跟随 A 空对象，就能随票卡一起移动、转动和缩放。

1. 基础分析完成后，打开工作区的镜头详情，在「区域位置跟踪」里读取定帧图。框住第一个清晰标记，设置跟踪结束时间，点击「跟踪此区域」。
2. 点击「设为 A，添加第二点」。在同一张定帧图上框住第二个标记，点击「跟踪 B 区域」。选两个相隔较远、各自清晰的小区域，框内尽量少带背景。两次跟踪的首帧与结束时间会锁定。
3. 检查 A 和 B 确实属于同一个刚性平面，再确认并计算双点姿态。界面给出位置、连续转角和等比缩放。任一点被遮住或失去唯一匹配时，结果停在共同确认的区间。
4. 导出双点 JSX 并在 AE 中运行。新合成中的 A 空对象带有位置、旋转和缩放关键帧，B 子空对象用于核对第二个标记。首个实测点对应合成零秒。把素材的相应源时间对齐到合成零秒后，可将自己的标注图层设为 A 的子层。

两个不同图层上的点同样能算出一组转角和缩放。制作前可再找第三处图案细节，对照原片检查它是否也随这组变换移动。遇到变形、明显透视或高速转圈时，应分段检查。两个采样时刻之间完整转过一圈，可能在两个采样画面上呈现相同方向。

## 回看片中实测位置

单框跟踪完成后可逐个查看采样点的原片画面。十字标出该时刻测得的中心。选择首个未确认帧可查看遮挡发生在哪里。最大偏移和最快采样区间按钮可帮助定位需要细调的关键帧。最快区间使用采样点之间的路程和实际时间计算平均速度。
