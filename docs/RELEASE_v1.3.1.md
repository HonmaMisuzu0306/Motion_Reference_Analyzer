# v1.3.1 · 竖屏与镜像素材

手机拍摄的视频有时以横屏像素编码，靠容器的旋转标记告诉播放器如何显示。本版在导入、分镜、代表帧、单帧定位、选区、文字识别和运动跟踪时统一使用显示方向。0°、90°、180°、270° 以及这四个方向的镜像均可识别。遇到斜切、透视或逐帧变化的显示矩阵时，请先将显示变换烘焙到素材，再重新导入。

一段编码画幅为 320 × 180 的水平往返样片，加上逆时针 90° 标记后，播放画面是 180 × 320，运动变为向上再返回。本版整片和片段分析均按竖屏生成 Position Y 曲线，导出的 AE 合成也是 180 × 320。留边建议随画面方向变化。

如果素材在旧版中分析过，重新打开项目并分析，即可刷新显示尺寸与测量；旧片段需要重新分析才能获得新的方向。新版片段记录保存自己的画幅与帧率，回看或导出时使用该次分析的尺寸。

同时修复了部分非零起始时间 MKV 在工作区中预览黑屏的问题。测试样片带 B 帧、旋转镜像以及延迟音轨，修复后预览可解码全部 48 帧；画面、显示矩阵和音画相对时钟均已核对。

开发环境使用 Python 3.12 及 PyAV 19.0.2。Windows 安装包内含运行时。此版本未签名，实际 AE 渲染和覆盖升级仍待验证。
对于非方形像素（SAR 不等于 1:1）的素材，本版仍以像素宽高建立方形像素 AE 合成。请先转换为方形像素、保持原播放比例，再使用数值位置和留边建议。
