# v1.8.0 · 从参考片估算叠化的不透明度

想复现两张海报之间的叠化时，可以从参考片上读出第二张海报在各个时刻需要显示多少。工作区的「测量叠化」使用本地视频像素，安装后即可使用。

1. 导入视频。在「片段」区设置入点和出点，让选区完整包含一次叠化，并在两端各留至少 0.15 秒的静止画面。单次测量最长 6 秒、最多 360 帧。
2. 点击「测量叠化」。成功时，表中列出原视频的采样时间、相对选区入点的合成时间，以及估算的顶层不透明度。点击源时间可以回看片中对应的画面。
3. 在 AE 中把选区入点对齐到合成零秒。起始静帧放在底层，保持 100% 不透明度；结束静帧放在顶层，使用正常混合模式。按表在顶层的「不透明度」上设置线性关键帧。中间的关键帧保留了参考片里可见的快慢变化。
4. 在局部记录中可重新打开测量，或导出 Markdown 制作表和 JSON。使用完整「分析片段」时，符合条件的短片段也会显示这张表。

测量对象是两张静止画面之间的全画面混合比例。色彩空间、编码和 AE 的混合设置都会影响复现效果，可在中间帧叠放对照。两端画面仍在移动、主体被擦除、画面只有亮度变化，或选区内出现硬切时，软件可能只给出重选提示。未采到的原工程关键帧和插值设置无法从参考片中确定。
