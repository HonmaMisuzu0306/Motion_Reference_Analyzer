# v1.9.0 · 把参考片中的叠化带进 After Effects

从参考片中量出叠化后，现在可以一次导出两张实测静帧和一份 AE 脚本。运行脚本会新建合成，将起始画面放在底层，结束画面放在顶层，并写入顶层的不透明度关键帧。两层素材都可替换。

1. 导入参考视频，设置一段最长 6 秒、最多 360 帧的选区。包含一次完整的全画面叠化，并在两端各留至少 0.15 秒静止画面。
2. 点击「测量叠化」。在局部记录中查看源时间、合成时间和不透明度，再点击「导出 AE 叠化素材包」。导出需要能读取与测量记录相符的原片。已有的不透明度记录也可以导出。
3. 把 ZIP 全部解压到一个目录，在 AE 的「文件 → 脚本 → 运行脚本文件」中选择 `create-blend.jsx`。请把 `start.png` 和 `end.png` 与脚本放在一起，并在使用工程期间保留这两张图。
4. 新合成的零秒对应选区入点。两张图使用已转正的显示画幅与方形像素。顶层关键帧以原视频的秒数为依据，采用线性插值。对于可变帧率视频，合成使用平均帧率作时间网格。源帧之间的实际取样间隔保存在关键帧时间里。

本版改进了亮底和暗底静帧之间的叠化测量，同时检查各区域的纹理变化，减少渐亮时出现角标、渐变光斑或暗角造成的误判。压缩严重或细节太少时，软件可能只给出重选提示。两张图按表混合可以复现成片中观察到的变化，具体效果取决于 AE 的颜色管理和混合设置。
