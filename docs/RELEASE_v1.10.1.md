# v1.10.1 · 桌面界面更新

本版采用 [PR #1](https://github.com/HonmaMisuzu0306/Motion_Reference_Analyzer/pull/1) 的深色界面。项目页、分析工作台、参考库、模型和设置使用统一的视觉样式，节奏时间轴与镜头信息也更容易对照。感谢 `zyc2pi` 提供界面设计与实现。

- 顶部操作空间不足时按组换行。在较矮的窗口里可向下滚动工作台，查看节奏时间轴。
- 镜头详情的代表帧按原比例显示。开启「文字轨迹平均范围」后，框与图片使用同一显示区域，方便核对竖屏、4:3 和超宽画面。

Windows x64 安装包和分析核心的版本均为 `1.10.1`。安装前退出正在运行的 MRA，并可用 `SHA256SUMS.txt` 校验下载文件。
