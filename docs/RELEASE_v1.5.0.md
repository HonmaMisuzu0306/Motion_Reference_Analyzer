# v1.5.0 · 在导出前预览 AE 试作运动

选中有完整实测运动的镜头，在「关键帧试作方案」中拖动「预览时间」。三个校准标记使用与导出 JSX 相同的画幅、中心锚点和线性关键帧，可用来查看位置、缩放和旋转如何一起变化。点击「上一个关键帧」或「下一个关键帧」可在各属性的不同转折时刻间移动。在工作区或已关联原片的选区中，点击「查看原片」即可核对同一源时间。

例如，在一段起点和终点相同的平移镜头中，先跳到中间关键帧查看位移峰值，再回到末帧，即可识别往返运动。试作预览覆盖保存的采样起止时间，显示导出脚本使用的静态标记；它不会重建原素材内容、缓动、运动模糊或未测量的图层运动。缺少原始画幅、有效曲线或时间覆盖的记录仍可查看文字建议。

## 慢速分层运动

相邻采样帧上的两块微小位移，可能被拟合成一个单一缩放。现在对符合条件的慢镜头增加数量有上限、相互分开的跨帧复核。只有重复取得区域运动互相矛盾的证据时，才拒绝该全局轨迹。单次长距离跟踪失败不会单独否决原有轨迹。

在四秒的真实编码合成样片中，慢速分屏的相邻 32 个帧对均可跟踪，跨帧复核两次确认冲突，因此程序保留诊断并拒绝全局运动 JSX。另一段真实慢平移对照则通过复核并可导出。低纹理、遮挡、长镜头中没有采到的间隔仍需结合原片判断。

已有项目重新分析后可获得跨帧复核。未重新分析的历史记录保留当时的结果。几何测试核对了应用 SVG 与生成的 JSX 属性之间的对应关系；真实 AE 渲染、外部模型推理和覆盖升级仍需另行验证。

## 固定样片验证

在 16 个四秒编码样片区间中，包含低速分屏、真实慢平移、缩放、旋转、往返、遮挡、可变帧时间和带静止 HUD 的平移。1.4.0 在六个分屏区间误发全局曲线，本版均识别为冲突。对于带小 HUD 的真实平移，本版在全画幅证据已成立后重新核对所选模型的一致点，保留 X/Y 位移，去除了原先的虚假缩放。本组 16 个区间均达到预设标准，实际素材请继续对照原片核对。

试用时可从三个入口打开标记预览。工作区和选区可从当前时刻跳回原片，资料库可单独检查已保存轨迹。按「上一个关键帧」和「下一个关键帧」会按四条通道全部保留点的时间顺序跳转，同一时刻只停一次。
