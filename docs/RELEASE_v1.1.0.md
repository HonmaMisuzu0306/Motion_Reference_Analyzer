# v1.1.0 源码预览版

日期：2026-10-28。此版本为本地开发交付，提供源码与 `MRA-1.1.0-x64-setup.exe`，尚未发布 GitHub Release。

## 视频分析

- 整片与选区共享分镜判断，减少快速平移和单帧闪白造成的误切。
- 使用实际解码时间与严格区间边界，代表帧记录实际来源时间，修复联系表颜色互换。
- 保存连续、分段运动轨迹，识别往返运动；跟踪中断时明确显示缺失，避免拼接错误运动。
- 按实际时间评估稳定度与抖动；逐帧处理减少运动分析内存占用。
- 分析结果、保存和缓存核验视频内容，源文件变化时保留上次已验证结果。

## AE 制作建议

- 展示位移、缩放、旋转的实测曲线、时间覆盖、参数范围与关键帧表。
- 工作区、参考库和片段分析支持导出 JSX，创建独立试作合成与线性关键帧。
- 单帧语义只描述静态画面；有可靠连续 CV 证据时才提供实测时间动画。
- 参数近似来自画面测量，不能还原原作者图层、工程或缓动。使用方式见 [AE 工作流](AE_MOTION_WORKFLOW.md)。

## 验证与已知边界

交付包附自动检查记录 `validation-summary.json`、合成演示及基准结果。覆盖 Python 核心、前端测试与生产构建；JSX 通过接口替身执行检查及浏览器导出验收。

合成分镜评估包含 11 类素材；运动评估包含 10 类素材、20 个完整或局部区间。合成成绩不能代表真实 MAD/OP/PV 准确率。

快速运动在默认采样率下仍可能缺失；纯色插镜与闪光可能混淆。Windows 程序已编译，内置服务独立启动、视频与音频分析、保存和导出已验收；OCR 运行库加载及桌面端服务身份检查通过。真实外部模型推理、After Effects 渲染、已有安装上的升级与卸载流程尚未验证。原生界面截图验收因自动化工具不可用而未完成。

源码构建见 [构建说明](V1_0_BUILD_GUIDE.md)。旧版安装器下载保留于 README；该安装器不包含本次新增能力。
