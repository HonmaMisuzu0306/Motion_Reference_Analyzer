# V1.0 中文术语与素材

| 数据 / 原词 | 用户界面 |
|---|---|
| Shot | 镜头 |
| Inspector | 镜头详情 |
| Measured Motion | 运动测量 |
| Typography | 文字与排版 |
| Track | 文字轨迹 |
| AE Recipe | AE 制作建议 |
| Hypothesis | 实现推测 |
| Beat / onset | 节拍 / 瞬态 |
| unavailable / unknown / skipped | 不可用 / 无法判断 / 已省略 |
| zoom_in / zoom_out | 推近 / 拉远 |

正常界面通过集中 labels 显示中文；技术 JSON 保留键、枚举和历史输出。
AE 效果名称、模型标识、编码及文件名可保留原名称。
视觉与排版 prompt 为 v3-zh：自然语言中文、结构键与枚举兼容，并据版本隔离缓存。

取景框+运动轨迹标识、操作 SVG 图标与主题为本项目原创，无 Adobe 素材复制。
源文件为 `apps/desktop/src/design/mra-mark.svg` 和 `icons.tsx`；ICO/PNG 由生成脚本从几何形状输出，无字体依赖。
界面参考资料与官方来源见 `V1_0_DESIGN_RESEARCH.md`；品牌采用 MRA，未使用 After Effects 标识。
