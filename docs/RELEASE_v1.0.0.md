# MRA 1.0.0

发布平台：Windows 10/11 x64。安装包自包含分析核心，无需另装Python、Node或Rust。下载入口为[GitHub Release v1.0.0](https://github.com/HonmaMisuzu0306/Motion_Reference_Analyzer/releases/tag/v1.0.0)。

## 主要功能

- AE风格深色工作台、原创图标与中文界面，镜头、视频预览、详情和音频轨道协同，面板布局可保存。
- 分镜、传统CV运动测量、音频节奏和切镜同步；外部本地视觉模型提供画面语义、效果推测及AE制作建议。
- 外部PP-OCRv5文字检测、识别、追踪与排版分析，已安装模型发现、目录校验和状态提示。
- 一键分析当前帧、按实际PTS准确定位、上一帧/下一帧微调；静态画面不推断运动或动画。
- 自选最长60秒片段，入点/出点、当前镜头填入及范围播放；跨镜头分别分析，少于8秒不估计BPM。
- 局部分析独立记录、后台进度、结果回看、源时间定位、重新分析为新记录，JSON/Markdown导出及部分完成警告。
- 项目保存与恢复、内容身份校验重连、参考库搜索/标签、旧库副本导入，原镜头和标签保留。
- 模型页提供配置建议与官网入口；模型权重由用户自行下载，软件不打包或下载权重。基础分析无需视觉/OCR模型。

## 验证范围

发布前核心182项、前端15项回归测试通过，Ruff与TypeScript/Vite生产构建通过。冻结核心的真实qwen3-vl:4b及外部PP-OCRv5验收包含合成中日文字视频、准确单帧、跨镜头片段、导出及重启回看。原生桌面验收包含一键提交、逐帧定位、范围播放、历史跳转、导出及新记录重试。

Windows安装更新、schema5→6迁移、旧业务表与模型设置保留、关闭时回收本实例后台和重启恢复均已验证。未评估所有自然视频的OCR、运动或节拍准确率，模型制作建议属于推测。极短单画面片段降为静态分析。暂不支持批量选区、ROI、任务取消和断点续算。

## 下载与更新

- `MRA-1.0.0-x64-setup.exe`：Windows x64安装器，本版未进行代码签名。
- `SHA256SUMS.txt`：下载文件SHA256校验。
- `MRA-1.0.0-docs-and-notices.zip`：使用/构建说明、第三方组件版本和上游许可文本。

数据默认保存于`%LOCALAPPDATA%/MotionReferenceAnalyzer`。更新前可关闭应用并备份该目录。schema6不能直接由旧schema5程序读取；回退应先保存新版数据，避免覆盖新增记录。

使用和模型配置见[使用说明](V1_0_USAGE.md)，源码构建见[构建说明](V1_0_BUILD_GUIDE.md)。源码采用MIT；第三方组件及用户自行下载的模型遵循各自上游许可。
