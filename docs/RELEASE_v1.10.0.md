# v1.10.0 · 对照原片复现叠化亮度

两张图用相同的不透明度叠化，混合方式不同，中间帧的亮度也会不同。「测量叠化」现在会比较直接混合解码 RGB 数值、按 sRGB 曲线转换到线性光再混合这两种结果，用中间帧给出制作建议。

- 选取一次完整的静帧叠化，两端各留至少 0.15 秒静止画面，点击「测量叠化」。当各区域的像素足以区分两种方式时，记录会显示更接近原片的方式及对应的不透明度。证据接近时，界面会提示按解码 RGB 估算。显式标记为 HDR 或宽色域的片段需要先准备 SDR 转换副本。
- 点击「导出 AE 叠化素材包」，完整解压，在 AE 的「文件 → 脚本 → 运行脚本文件」中选择 `create-blend.jsx`。主合成提供可编辑的两张静帧和关键帧。
- 素材包会从原片提取顶层不透明度最接近 50% 的一个实际中间帧。打开同一项目文件夹里的 `MRA - compare source frame`，顶层用差值模式对照原片和导出配方，较暗处表示像素更接近。独奏顶层可查看原片，关闭顶层可查看重建。说明文件列出对照帧的源时间和不透明度。
- 如需尝试不同的颜色混合设置，请在独立测试工程中操作。脚本沿用当前 AE 工程的颜色设置。压缩误差、源图颜色配置以及解码都会影响比较结果。

本版也修复了独立叠化测量漏掉部分暗到亮匀速过渡，以及 Windows 同时导出同一素材包时偶发保存失败的问题。已有测量记录仍可导出，再次测量可获得颜色混合建议。

发布前复核补充修复了重新分镜后的保存与恢复。重开项目和项目镜头计数使用本次分析的镜头集合，标签操作命中当前镜头，历史镜头与标签仍可在参考库中查阅。重分析遇到项目文件写入失败时，可继续回看上次已保存结果；结果已成功入库时，界面会提示项目文件写入警告。

本次发布回归：核心 715 项、前端 107 项、Rust 宿主 1 项通过。已用合成视频检查桌面导入、基础分析、保存与重开，以及冻结程序的重分析、重启恢复、标签归属和叠化素材包导出；导出的原片对照 PNG 与指定源帧逐像素一致。
