# v1.4.0 · 区分画面运动与局部运动

**从字幕卡或移动前景拆解 AE 动画时，可以先看跟踪点分布。** 以前，一张在固定画面里移动的高对比卡片可能产生很高的跟踪评分，进而生成整个合成的位移关键帧。本版分别检查跟踪点在画幅中的覆盖范围，以及画面各处的运动是否一致。

| 分析结果 | 如何在 AE 中使用 |
| --- | --- |
| 画幅多处支持同一变换，轨迹连续可用 | 核对参考帧后，导出普通或留边的 AE 试作脚本。 |
| 跟踪点仅集中在局部 | 对照原片中相距较远的背景细节。若只有字幕或图层在动，单独跟踪和制作该图层。 |
| 多组运动冲突且没有充分证据支持全画幅变换 | 分别核对各区域，按图层拆解。该区间不生成一条合成级的实测曲线。 |

基础分析即可使用这些判断。相同素材在旧版本中生成的测量可能没有保存空间分布证据，查看或导出时会提示这一点。重新分析可得到本版判断。

在 640 × 360 的编码样片中，一个小图块向右移动 69 像素，旧版据此生成整幅右移；本版将其标为局部证据。同样位移出现在全画幅纹理上时，仍能生成约 69 像素的横移曲线。这里判断的是支持全局几何的可见证据；仅凭分布不能识别人物或判断拍摄者的意图。遮挡、低纹理、运动模糊和幅度很小的分层运动仍需人工核对。

## 非方形像素素材

导入会先把编码画面转换为方形像素，再应用文件记录的旋转和镜像。代表帧、OCR、CV、片段和 AE 合成共用这个画幅。对于 320 × 180、像素宽高比 3:4、逆时针 90° 的样片，输出为 **180 × 240**，向上位移约 47.5 像素，底部留边 48 像素。已有工程需重新分析以更新画幅和测量。

尺寸换算将宽度取至最接近的整数像素。异常比例会在分配扩大画布之前被拒绝，可先将素材转换为常规方形像素尺寸后导入。真实 AE 渲染、外部模型推理与覆盖升级需另行验证。

在独立分屏对照中，两半以不同速度移动时，六组样片均未生成统一的相机曲线；真平移、缩放、旋转和复合变换四个对照仍有连续轨迹。高对比卡片向右、可观察背景向左的测试中，背景真值为 −46 像素，计算结果约为 −46 像素。这些数值来自固定合成样片。
已知边界：在 4 秒分屏中，若一侧每原始帧只移动 0.25–0.5 像素，帧对差异很小，累计结果仍可能出现虚假的整体缩放。对长镜头的微小缩放，请对照画面两侧及中间位置确认。
